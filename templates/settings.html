接入步骤

  1. 复制模板：copy .env.example .env（macOS / Linux 用 cp）。
  2. 填入自己的 LLM_API_KEY，按服务商修改 LLM_BASE_URL 与 LLM_MODEL。
  3. 重启服务：python app.py。
  4. 回到本页点击「测试连接」确认可用，再回工作台生成。
LLM_API_KEY=sk-你的Key
LLM_BASE_URL=https://api.deepseek.com/v1
LLM_MODEL=deepseek-chat

兼容任何 OpenAI 风格的 /chat/completions 接口。 如果服务商不支持 response_format，客户端会自动去掉该参数重试。

密钥安全约定

  • .gitignore 已忽略 .env、data/ 与常见缓存目录，Key 不会被提交。
  • 程序只从 .env / 环境变量读取 Key；页面与 API 只返回掩码，不返回完整值。
  • 日志只记录阶段、耗时、任务数等元信息，不打印请求头与 Key。
  • 方案 JSON 与导出文件不包含 Key，只包含模型名与 base_url。
