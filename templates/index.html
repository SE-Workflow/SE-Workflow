01 · 输入

一句需求或专业规格

抽象短句、长段 PRD、结构化功能清单都可以。系统会原样交给大模型，不做关键词模板匹配。

02 · 任务分解

LLM 拆出一个个任务方框

阶段一要求模型输出严格 JSON：任务 ID、名称、描述、所属模块、优先级、工作量、Agent 建议与验收标准。

03 · Agent 编排

LLM 决定连线与排版

阶段二以任务清单为输入，生成依赖边、阶段分层、并行分组，并为每个任务指派承接 Agent。

🖱️

点击方框即可编辑

修改名称、描述、模块、优先级、工作量、验收标准与承接 Agent；支持新增 / 删除任务、增删依赖连线。

🔀

图即结果，实时同步

vis-network 渲染分层 DAG；编辑后立即重算层级、关键路径与统计，并同步回写底层 JSON。
